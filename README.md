# Password Tracker

A simple password tracker built using **HTML, CSS, JavaScript, Axios, and CrudCrud API**.

### Features

* Add website, username and password
* View all saved passwords
* Edit passwords
* Delete passwords
* Search passwords by website name
* Show total number of saved passwords
* Show/hide password
* Data is stored using the CrudCrud API

### Tech Used

* HTML
* CSS
* JavaScript
* Axios
* REST API / CrudCrud
